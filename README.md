# cybersec-odyssey

My journey from complete beginner to junior SOC analyst. This repo is where I document what I learn in cybersecurity, Python, and eventually AI security.

## Background

I'm studying Applied Computer Science, specializing in Cybersecurity and Digital Forensics. This repo tracks the practical side of that: wargames, CTFs, and lab work. I try to write these up the way I'd want to read someone else's, showing the reasoning, not just the answer.

## Structure

```
overthewire/     write-ups from the OverTheWire Bandit wargame (Linux fundamentals)
```

More folders will show up as I move through picoCTF, Hack The Box, and TryHackMe.

## Current focus

Right now I'm working on Linux fundamentals, Python basics, and CompTIA Security+ (SY0-701) theory. The goal is a junior SOC analyst role.

## How the write-ups are structured

Each entry follows the same format: problem, approach, solution, what I learned. I leave out passwords and flags on purpose. The point is showing the method, not handing out answers.
